Enter your target polynomial ρ(x, S) below, choose options, then click Generate MATLAB Code. Paste the output into a .m file and run it in MATLAB. The script will print the LaTeX sum-of-q formula and the save code you can paste into the main game.

Options

Unchecked → each q used at most once (binary 0/1 variables)
Checked → T is always the full set X (fast, unique, no toolbox needed)
Level-by-level: place target entries, then at each larger size equalise all alternatives in each subset to the same ρ. Always non-negative; k ignored; no toolbox.

Constant Term

k =
Adds k to ρ(x, X) for every alternative x.
By normalization Σx p(x,X)=1, this contributes k as a constant to the functional.
If Standard BM with k at all x fails, the solver tries each alternative one by one.
